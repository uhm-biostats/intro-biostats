Assumptions of ANOVA for groups

  • Random and independent samples
  • Normal distribution for each group
  • Equal variances within each group

What to do if assumptions are not met?

  • Do ANOVA anyway (if deviations are minor)
  • Transform
  • More advanced stats

Interpreting ANOVA for groups

ANOVA does not tell you which group(s) is/are different! Just that a difference exists

Interpreting ANOVA for groups

If we want to know which groups are different, we need to do a “post hoc” test

  • Post hoc tests are designed to account for multiple comparisons
  • What are multiple comparisons and why can’t we just do multiple \(t\)-tests?

Pos hoc tests and multiple comparisons

Which groups are different? Just do \(t\)-tests between all pairwise comparisons, right?

  • The problem is that doing multiple \(t\)-tests leads to a false positive rate \(> \alpha\)
  • If we do 3 pairwise comparisons with \(t\)-tests and \(\alpha = 0.05\) for each one, then probability of at least 1 false positive is:
prob_false_positive <- 1 - dbinom(0, size = 3, prob = 0.05)
prob_false_positive
[1] 0.142625

Pos hoc tests and multiple comparisons

prob_false_positive <- 1 - dbinom(0, size = 3, prob = 0.05)
prob_false_positive
[1] 0.142625

Each \(t\)-test is like a coin toss with “heads = false positive”, the more you do, the more likely you’ll get at least one “heads = false positive”

Pos hoc tests and multiple comparisons

So we use a post hoc test:

# annoying, but we have to pass the model through the `aov` function
aov_group <- aov(mod_group)
# "Tukey Honest Significant Difference"
TukeyHSD(aov_group)

Pos hoc tests and multiple comparisons

So we use a post hoc test:

# "Tukey Honest Significant Difference"
TukeyHSD(aov_group)

Example multi-factor ANOVA in R

# make some pretend data
restoration <- factor(rep(c("restored", "control"), each = 30))
impact <- factor(rep(c("low", "high"), 30),
                 levels = c("low", "high"))

# compute expected response
fish_biomass <- -1 * as.numeric(impact) + 3 * as.numeric(restoration) -
  1 * as.numeric(impact) * as.numeric(restoration)

# add some noise
set.seed(123)
fish_biomass <- fish_biomass + rnorm(60, mean = 0, sd = 1)

dat <- data.frame(restoration, impact, fish_biomass)
